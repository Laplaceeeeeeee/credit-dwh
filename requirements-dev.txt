# 为什么要单开一个文件：`requirements.txt` 是**运行时**依赖；
# 这里的 pytest / ruff / pyyaml 只在"开发 + CI"里用。
# 平台相关依赖（pyflink / kafka-python 等，见第 19 步）**一律不进 CI** ——
# 它们是平台相关、装得慢、还容易挂，会让 CI 变成噪音源。
#
# 为什么**锁到具体小版本**：CI 的结论必须可复现。
# `pip install ruff` 这种写法会让"某天 CI 突然变红"变成 ruff 的锅 ——
# 这里两头都锁：requirements-dev.txt 锁版本 + ruff.toml 锁规则集。
