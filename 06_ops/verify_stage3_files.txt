# ============================================================
# 阶段三交付物清单（一行一个路径；# 开头为注释）
#
# ⚠️ 为什么清单单独放一个 UTF-8 文本文件，而不是写进 .ps1：
#    BOM-less 的 .ps1 在 Windows PowerShell 5.1 下会被按 GBK 读取，
#    中文路径会把字符串引号截断，报 ParserError（阶段二踩过）。
#    所以 .ps1 保持 **纯 ASCII**，中文路径全部放这里，用 -Encoding UTF8 读。
#
# ⚠️ 本清单**按仓库实际文件名逐条核对过**，不是照抄指导书示例：
#    指导书里写的 `08_benchmark/E5_三引擎基准.md`、`exp/E4_verify.sql` 在仓库里
#    并不存在（实际是 `引擎选型结论.md`，E4 也没有 verify.sql）。
